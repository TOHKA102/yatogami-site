## 📖 项目简介

**Yatogami ACG Sanctuary** 是一个专为二次元爱好者打造的个人向综合展示平台。项目在视觉设计上融入了大量 ACG 元素（以《约会大作战》夜刀神十香为核心视觉意象），旨在为自己提供一个记录日常、展示数字媒体技术作品（3D 模型、剪辑、书法与动效）以及沉淀 Galgame/动漫评测的精神栖息地。

---

## 🛠️ 技术栈与工具链

本项目在开发与部署过程中运用了现代前端与自动化部署工具：

* **核心架构**：HTML5 / CSS3 / JavaScript (或现代前端组件化方案)
* **样式与UI**：定制 CSS / Flexbox / Grid 响应式布局，融入个性化二次元视觉主题
* **版本控制**：Git / GitHub 仓库管理
* **自动部署**：GitHub Actions 持续集成与自动发布
* **托管服务**：GitHub Pages + Cloudflare Pages 双线加速与自定义域名绑定 (`yatogami.bbroot.com`)
